# Network Simulator

A lightweight **C++ network simulation project** that models basic network communication between computers, switches, and routers.

## Features

* Simulates computers, switches, and routers
* Device identification using IP and MAC addresses
* Basic packet forwarding and routing
* Device status and network connectivity simulation
* Console-based network activity visualization
* Object-oriented C++ design

## Network Structure

```text
PC1 ──┐
      ├── Switch ── Router
PC2 ──┘
```

## Technologies

* **C++**
* Object-Oriented Programming
* GCC / MSYS2
* Command Line Interface

## Project Purpose

This project is built for learning and demonstrating **networking concepts through C++**, including device communication, routing, switching, and object-oriented system design.
